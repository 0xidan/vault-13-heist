Vault 13 Heist: a turn-based heist game built for make.fun. Plan the crew, sneak past cameras, crack the vault, and escape with the loot. The game runs in a desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
